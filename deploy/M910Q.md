# Screenroom box: Lenovo ThinkCentre M910q

The M910q becomes a dedicated Screenroom player: it starts behind a Screenroom splash, goes straight into Screenroom, and has no desktop, no accounts and no subscriptions.

## 1. What to buy

| Part | Pick | Why |
|---|---|---|
| M910q CPU | **i5-7500T, i5-7600T or i7-7700T** (7th gen, "HD 630") | Hardware decoding of 10-bit H.265 (4K HDR). Skip i5-6500T / i7-6700T. |
| RAM | 8 GB | Plenty. |
| System drive | Any M.2 NVMe *or* 2.5" SSD, 128 GB+ | Screenroom uses about 10 GB. |
| Movie drive (optional) | 2.5" SSD/HDD in the spare bay, or the M.2 slot | Becomes the library automatically. |
| TV cable | **DisplayPort to HDMI 2.0 *active* adapter or cable** (4K 60 Hz) | DisplayPort gives 4K at 60 Hz. The optional HDMI port on some M910q units only does 4K at 24 Hz. |
| Remote | Phone (built in), a USB/2.4 GHz remote, a Bluetooth remote or game controller | The M910q has no HDMI-CEC. A **Pulse-Eight USB-CEC adapter** adds TV-remote control. |

Sound: Dolby and DTS go to your receiver/soundbar over the same cable. HDR video is shown tone-mapped to normal picture (Linux limitation).

## 2. Make the installer USB stick

1. Download **Screenroom-Installer-0.5.N.iso** from your repository's Releases page (the newest "Screenroom for Linux / M910q" release).
2. Write it to a USB stick (2 GB or larger) with **balenaEtcher** ("Flash from file" → pick the ISO → pick the stick → Flash). This erases the stick.

## 3. Prepare the M910q (once)

Press **F1** at the Lenovo logo to open the BIOS setup:

- **Startup → Boot Mode / CSM:** UEFI only (CSM disabled).
- **Security → Secure Boot:** Disabled. Debian supports Secure Boot, but turning it off avoids problems with some drivers.
- **Power → After Power Loss:** Power On, so the box comes back after a power cut.
- **Devices → (optional) Video:** if there's a "Primary display" option, leave it on Auto.

Press F10 to save.

## 4. Install

1. Plug in a **network cable** (needed during installation only), the TV, and the USB stick.
2. Turn the M910q on and press **F12** at the Lenovo logo, then choose the USB stick.
3. The Screenroom installer menu appears. Wait 15 seconds or press Enter. **It erases the computer's main drive.**
4. Wait 15–30 minutes. When the computer restarts, remove the USB stick. It starts into Screenroom.

Which drive gets erased: the installer only uses an internal drive, never a USB drive. If the computer has two internal drives, it installs on the one that has the old operating system (the Windows the PC came with) or the one that's blank. If it can't tell, it stops and erases nothing. Then remove the movie drive, install, and put it back.

## 5. First start

Open **Settings** (Menu/Settings key, controller Start, or the phone remote):

- **Wi-Fi:** Find Wi-Fi networks → pick yours → type the password (or type it on your phone in the phone remote's "Type on TV" box). The network cable can then be removed.
- **Bluetooth:** Pair a remote or controller (put it in pairing mode first).
- **Phone remote:** scan the QR code.
- **Audio:** passthrough on if your receiver decodes Dolby/DTS. Pick the HDMI/DisplayPort output.

## Getting movies on it

- **Drive inside the M910q:** set up automatically at start-up. A drive that already has movies (exFAT, NTFS or Linux formats) is used as it is, and nothing on it is changed. A completely blank drive is formatted once for Screenroom.
- **USB drive:** plug it in; it appears in the library.
- **From a Mac/PC:** Finder → Go → Connect to Server → `smb://screenroom.local` → the Screenroom share.
- **From a phone:** Settings → Add media → scan the QR code → upload.

## Looking after it

- **Updates:** Settings → System → **Check for updates** installs the newest Screenroom from your GitHub releases. Security updates for the system install themselves.
- **Power button:** shuts down cleanly. The box never sleeps.
- **Repairs:** Settings → System shows a maintenance login (`ssh admin@screenroom.local` + password) for fixing things from a computer on your network.
- **Starting over:** boot the installer USB again.
